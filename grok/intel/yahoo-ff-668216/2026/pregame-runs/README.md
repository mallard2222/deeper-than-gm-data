# Pregame run records

From 2026-11-14 every pregame routine run inside an active window writes one file here, even when nothing is actionable:
`YYYY-MM-DD-HHMM-pregame.md` (CT) with: run time, Yahoo pull status (HTTP code / failure), starters checked with game time and status, actions taken (only standing-rule swaps) or "none", alerts relayed to FF GM, and gaps. A missing file for a scheduled run means the run did not record — treat as unknown, not "no change".
